# Kalorije

Lična aplikacija za praćenje kalorija (po uzoru na MyFitnessPal), prilagođena Srbiji.

- Otvori `index.html` u browseru ili na telefonu.
- Profil (ikonica gore desno): pol, visina, težina, datum rođenja, aktivnost → BMI, bazalni metabolizam i dnevna potrošnja (Mifflin-St Jeor × faktor aktivnosti).
- Kazaljka prikazuje unete kalorije u odnosu na dnevnu potrošnju.
- Obroci: doručak, ručak, večera, užine, ostalo.
- Podaci se čuvaju lokalno u browseru (localStorage).
